Example B: parkour with a timer and a saved best time

Gold block = start, diamond block = finish. Times are in seconds.

{"handlers": [
  {"kind": "event", "event": "PLAYER_MOVE", "nodes": [
    {"action": "IF_PLAYER_STANDING_ON", "args": {"blocks": {"item": "minecraft:gold_block"}}, "children": [
      {"action": "VARIABLE_SET", "args": {"variable": {"var": "pk_start_%player_uuid%"}, "values": {"val": "CURRENT_UNIX_TIME"}}},
      {"action": "PLAYER_ACTION_BAR", "args": {"message": "§eTimer started!"}}
    ]},
    {"action": "IF_PLAYER_STANDING_ON", "elseIf": true, "args": {"blocks": {"item": "minecraft:diamond_block"}}, "children": [
      {"action": "IF_VARIABLE_EASY_COMPARE_NUMBER", "args": {"num1": {"var": "pk_start_%player_uuid%"}, "num2": 0}, "switches": {"state": 0}, "children": [
        {"action": "VARIABLE_DIFFERENCE", "args": {"variable": {"var": "pk_time_%player_uuid%"}, "number": {"val": "CURRENT_UNIX_TIME"}, "numbers": {"var": "pk_start_%player_uuid%"}}},
        {"action": "VARIABLE_QUOTIENT", "args": {"variable": {"var": "pk_time_%player_uuid%"}, "number": {"var": "pk_time_%player_uuid%"}, "numbers": 1000}},
        {"action": "VARIABLE_SET", "args": {"variable": {"var": "pk_start_%player_uuid%"}, "values": 0}},
        {"action": "PLAYER_MESSAGE", "args": {"texts": "§aFinish! Time: §e%var(pk_time_%player_uuid%)%§a s"}},
        {"action": "IF_VARIABLE_EXIST", "not": true, "args": {"variable": {"var": "pk_best_%player_uuid%", "save": true}}, "children": [
          {"action": "VARIABLE_SET", "args": {"variable": {"var": "pk_best_%player_uuid%", "save": true}, "values": {"var": "pk_time_%player_uuid%"}}}
        ]},
        {"action": "ELSE", "children": [
          {"action": "IF_VARIABLE_EASY_COMPARE_NUMBER", "args": {"num1": {"var": "pk_time_%player_uuid%"}, "num2": {"var": "pk_best_%player_uuid%", "save": true}}, "switches": {"state": 2}, "children": [
            {"action": "VARIABLE_SET", "args": {"variable": {"var": "pk_best_%player_uuid%", "save": true}, "values": {"var": "pk_time_%player_uuid%"}}},
            {"action": "PLAYER_MESSAGE", "args": {"texts": "§6New personal best!"}}
          ]}
        ]}
      ]}
    ]}
  ]}
]}

Notes: IF_VARIABLE_EASY_COMPARE_NUMBER state 0 = num1 > num2, 1 = >=, 2 = <, 3 = <=. pk_start is set to 0 at the finish so the finish counts once. pk_best is saved, so it survives restarts.

Example C: bossbar updated by a loop

{"handlers": [
  {"kind": "event", "event": "PLAYER_JOIN", "nodes": [
    {"action": "GAME_CREATE_BOSSBAR", "args": {"name": "hud", "title": "§eLoading..."}, "switches": {"state": 2, "state1": 0}},
    {"action": "PLAYER_SHOW_BOSSBAR", "args": {"name": "hud"}},
    {"action": "GAME_START_LOOP", "args": {"names": "hud_loop"}}
  ]},
  {"kind": "loop", "name": "hud_loop", "ticks": 20, "nodes": [
    {"action": "SELECT_RANDOM_PLAYER"},
    {"action": "VARIABLE_INCREMENT", "args": {"variable": {"var": "hud_seconds"}, "number": 1}},
    {"action": "GAME_SET_BOSSBAR_TITLE", "args": {"name": "hud", "title": "§eOnline: §f%value(PLOT_ONLINE)% §7| §eUptime: §f%var(hud_seconds)%s"}},
    {"action": "GAME_SET_BOSSBAR_PROGRESS", "args": {"name": "hud", "progress": "%math(mod(%var(hud_seconds)%, 60) * 100 / 60)%"}}
  ]}
]}

Notes: SELECT_RANDOM_PLAYER makes the rest of the loop run once, not once per player. Bossbar progress is 0..100. Bossbar color state: 0 red, 1 blue, 2 yellow, 3 green, 4 pink, 5 white, 6 purple; style state1: 0 solid, 1..4 = 6, 10, 12, 20 segments.

    {"action": "PLAYER_MESSAGE", "target": "ALL", "args": {"texts": "§c%victim% §7was killed by §a%player%"}}
  ]},
  {"kind": "function", "name": "update_kills", "nodes": [

Notes: in PLAYER_KILL_PLAYER the selection and %player% are the killer, %victim% is the killed player. The function runs for the same player and sees the same event. VARIABLE_INCREMENT without number adds 1.

Example E: a complete game: zombie waves and a hoe weapon

The player gets a hoe. A hit with it does 6 damage, a right click blasts the zombies around (2 s cooldown). A loop sends 4 zombies when none are left. 10 kills win; /play starts a new round. It follows section 14: the round has a phase guard, the zombies have a name and are removed at the start and the end, kills are counted only for named zombies while the round runs, and the zombies spawn at the world spawn, the only place that is surely free.

Events only change shared data (PLAYER_DEATH and PLAYER_QUIT remove the player from the alive list), so a death, a quit and a /play in the middle of the round are all handled the same way and the round can never end twice. The alive list holds names (%selected% when it is filled for every selected player). A player who joins during a round becomes a spectator until the next one. Top lists: DICT_SORT by value, descending, then read the first places with DICT_KEY_BY_INDEX / DICT_VALUE_BY_INDEX (positions start at 1); check DICT_SIZE first, because a missing place reads as the number 0.
