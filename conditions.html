IF_VARIABLE_EQUALSСПРАВОЧНАЯ ЗАПИСЬ

kind: condition | category: IF_VARIABLE | targets: none (tests values)

TRUE when obj is equal to at least one value in objects.

args:

  • objects (ANY, up to 27 values): values to compare with. Text values get their placeholders replaced.
  • obj (ANY): the value to check. Text written here is NOT read with placeholders (%player% stays as written). Put such text into objects or into a variable.

notes:

  • Numbers are compared by value. Other values must have the same type and content: text is case-sensitive, number 5 and text "5" are different, items must match fully (also the amount).
  • If obj is missing (for example a variable that does not exist), the result is TRUE only when objects is empty too.
  • Targets: any (checked for each target until one passes). Empty selection → FALSE.
IF_VARIABLE_NOT_EQUALSСПРАВОЧНАЯ ЗАПИСЬ

kind: condition | category: IF_VARIABLE | targets: none (tests values)

TRUE when obj is different from every value in objects.

args:

  • objects (ANY, up to 27 values): values to compare with. Text values get their placeholders replaced.
  • obj (ANY): the value to check. Text written here is NOT read with placeholders.

notes:

  • Numbers here are also compared by their kind: a whole-number game value (for example PLOT_ONLINE) counts as different from the same number written as a JSON number. To compare numbers, use IF_VARIABLE_EQUALS with "not": true or IF_VARIABLE_EASY_COMPARE_NUMBER.
  • If obj is missing, the result is TRUE only when objects is not empty.
  • Targets: all (every target must have no equal value). Empty selection → TRUE.
IF_VARIABLE_EASY_COMPARE_NUMBERСПРАВОЧНАЯ ЗАПИСЬ

kind: condition | category: IF_VARIABLE | targets: none (tests values)

TRUE when num1 compared with num2 passes the check chosen by state.

args:

  • num1 (NUMBER): the number to check. Missing or not a number → 0.
  • num2 (NUMBER): the number to compare with. Missing or not a number → 0.

markers:

  • state: 0 = num1 > num2 (default), 1 = num1 >= num2, 2 = num1 < num2, 3 = num1 <= num2

notes:

  • Text is read as a number after placeholders, so "%var(x)%" works.
  • Targets: first (only the first target is checked). Empty selection → FALSE.
IF_VARIABLE_COMPARE_NUMBERСПРАВОЧНАЯ ЗАПИСЬ

kind: condition | category: IF_VARIABLE | targets: none (tests values)

TRUE when number is above num1 and below num2 (a range check). Each bound is optional.

args:

  • number (NUMBER): the number to check.
  • num1 (NUMBER): lower bound: number must be greater than it. Optional.
  • num2 (NUMBER): upper bound: number must be less than it. Optional.

markers:

  • state1: 0 = number > num1 (default), 1 = number >= num1
  • state2: 0 = number < num2 (default), 1 = number <= num2

notes:

  • A missing bound is not checked. If both bounds are missing, the result is FALSE.
  • If number is missing or not a number, the result is TRUE only when both bounds are missing too.
  • Targets: first. Empty selection → FALSE.

kind: condition | category: IF_VARIABLE | targets: none (tests values)

TRUE when loc_in_range is inside the box between the corners loc1 and loc2. The corners may be given in any order; the edges count as inside.

args:

  • loc_in_range (LOCATION): the location to check.
  • loc1 (LOCATION): first corner of the box.

kind: condition | category: IF_VARIABLE | targets: none (tests values)

Compares two boxes: region 1 between loc1 and loc2, region 2 between loc3 and loc4.

args:

  • loc1 (LOCATION): first corner of region 1.
  • loc2 (LOCATION): second corner of region 1.
  • loc3 (LOCATION): first corner of region 2.
  • loc4 (LOCATION): second corner of region 2.

markers:

  • state: 0 = TRUE when the regions overlap or touch (default), 1 = TRUE when region 2 is fully inside region 1

notes:

  • For state 1, loc1 must be the smaller corner (lowest x, y and z) and loc2 the larger corner; this mode does not sort the corners. State 0 accepts corners in any order.
  • Any location missing → FALSE.
  • Targets: first. Empty selection → FALSE.

IF_PLAYER_LOOKING_ATСПРАВОЧНАЯ ЗАПИСЬ

kind: condition | category: IF_PLAYER_BLOCK_AND_WORLD | targets: players

TRUE when the block the player looks at is one of blocks OR is at one of locations, and it is not farther than distance.

args:

  • blocks (ITEM, up to 9 values): block items to compare with. A water or lava bucket means water or lava.
  • locations (LOCATION, up to 9 values): block positions to compare with.
  • distance (NUMBER): largest distance in blocks from the player's feet. Default: 5.

markers:

  • state: 0 = exact block type (default), 1 = ignore the block variant (all wool colors, all planks, logs, leaves, saplings, wooden slabs and stairs, signs, banners, beds, shulker boxes, and blocks that shared one id in old versions)

notes:

  • The looked-at block is the first non-air block along the view, up to 120 blocks. Water counts as a block.
  • With no blocks, the type test checks for air, so give blocks or locations.
  • Targets: all (a non-player fails). Empty selection → TRUE.

kind: condition | category: IF_PLAYER_BLOCK_AND_WORLD | targets: the current event

TRUE when the block of the current event is one of blocks OR is at one of locations.

args:

  • blocks (ITEM, up to 18 values): block items to compare with. A water or lava bucket means water or lava.
  • locations (LOCATION, up to 18 values): block positions to compare with.

markers:

  • state: 0 = exact block type (default), 1 = ignore the block variant (all wool colors, all planks, logs, leaves, saplings, wooden slabs and stairs, signs, banners, beds, shulker boxes, and blocks that shared one id in old versions)

notes:

  • Works in events with a block: PLAYER_BLOCK_PLACE, PLAYER_BLOCK_BREAK, PLAYER_BLOCK_DAMAGE, PLAYER_BLOCK_INTERACT and PLAYER_RIGHT_CLICK (clicked block), block events of the plot (PLOT_*), ENTITY_CHANGE_BLOCK, and other events that give a block value. Other events: FALSE plus an "incompatible event" warning.
  • The event has no block (for example a click in the air): TRUE only when both blocks and locations are empty.
  • With no blocks, the type test checks for air.
  • Targets: all (the same block for every target). Empty selection → TRUE.
IF_PLAYER_CLICKED_SLOT_EQUALSСПРАВОЧНАЯ ЗАПИСЬ

kind: condition | category: IF_PLAYER_INVENTORY_AND_ITEMS | targets: the current event

TRUE when the clicked slot of the current inventory event is one of slots.

args:

  • slots (NUMBER, up to 27 values): slot numbers inside the clicked inventory. A chest starts at 0 (top left). In the player's own inventory 0–8 is the hotbar and 9–35 the main part.

markers:

  • state: 0 = at least one dragged slot is in slots (default), 1 = every dragged slot is in slots

notes:

  • Works in PLAYER_CLICK_INVENTORY and PLAYER_DRAG_INVENTORY. In any other event it is FALSE (no warning).
  • state is used only in PLAYER_DRAG_INVENTORY. In PLAYER_CLICK_INVENTORY the one clicked slot must be in slots.
  • In a drag event with empty slots it is FALSE.
  • Targets: all. Empty selection → TRUE.
