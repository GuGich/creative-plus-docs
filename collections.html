kind: action | category: LIST | targets: none (runs once per selected target)

Writes the element at position index into output_var.

args:

  • list (LIST): the list. A variable or a literal list.
  • index (NUMBER): position, starting at 1. Decimals are cut (2.7 → 2). Default: 0 (out of range).
  • output_var (VARIABLE): where the element is written.

notes:

  • Out of range (below 1 or above the size) writes the number 0.
  • An inner list or dict is not copied: output_var then points to the same inner list, so changing it also changes the element.

kind: action | category: LIST | targets: none (runs once per selected target)

Inserts value at position index. Elements from that position move one place to the right.

LIST_SORTСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: LIST | targets: none (runs once per selected target)

Writes the elements of input_list sorted into output_list. The old elements of output_list are removed. input_list does not change unless it is the same variable.

args:

  • input_list (LIST): the list to sort. A variable or a literal list.
  • output_list (LIST): the list variable to write into. May be the same variable as input_list.

markers:

  • asc_sort: 0 = ascending, smallest first (default), 1 = descending, largest first

notes:

  • Numbers are sorted by value. Texts are sorted by character code: case-sensitive (B before a) and "10" before "9".
  • The list must hold only numbers or only texts. Mixed types, locations, items or inner collections give an error and output_list does not change.
  • If either list has 100000 or more elements, nothing happens. The size counts toward the element budget.

DICT_CREATE_OR_CLEARСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: VARIABLE_DICT | targets: none (runs once per selected target)

Clears the dict variable and fills it with key → value pairs. Creates the dict if it does not exist.

args:

  • dict (MAP): the dict variable to fill.
  • keys (TEXT, up to 9 values): keys. Placeholders are replaced; numbers become text (5 → "5").
  • values (ANY, up to 9 values): values. Text values get their placeholders replaced.

notes:

  • Pairs are made by position: key 1 with value 1, key 2 with value 2, and so on. Extra keys or values without a partner are ignored.
  • Empty slots and variables that do not exist are skipped, which shifts the pairing. Fill both lists without gaps.
  • If a key is given twice, the last value wins.

DICT_SORTСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: VARIABLE_DICT | targets: none (runs once per selected target)

Writes the pairs of input_dict into output_dict in sorted order. The old pairs of output_dict are removed.

args:

  • input_dict (MAP): the dict to sort. A variable or a literal dict.
  • output_dict (MAP): the dict variable to write into. May be the same variable as input_dict.

markers:

  • sort_by: 0 = sort by keys (default), 1 = sort by values
  • asc_sort: 0 = ascending (default), 1 = descending

notes:

  • By keys: keys that look like numbers are compared as numbers and come before other keys; other keys are compared as text (case-sensitive).
  • By values: numbers first (by value), then texts, then other values (not ordered among themselves).
  • Descending reverses the whole order, including these groups.
  • If either dict has 100000 or more pairs, nothing happens. The size counts toward the element budget.
