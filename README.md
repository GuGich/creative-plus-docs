# Creative+ Docs — статическая версия

Это обычный статический сайт на HTML, CSS и JavaScript. Нет VitePress, Node.js, npm, сборки и зависимостей.

## Публикация на GitHub Pages
1. Скопируй содержимое папки в корень репозитория `creative-plus-docs`.
2. В GitHub открой Settings → Pages.
3. Выбери Deploy from a branch → `main` → `/ (root)`.
4. Сохрани настройки.

Сайт открывается из `index.html`; все ресурсы подключены относительными путями, поэтому работает и в корне домена, и в подпапке GitHub Pages.
