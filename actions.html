Действия

Команды и операции, которые выполняются после запуска события или вызова функции.

Действия изменяют состояние игры: отправляют сообщения, управляют игроками и сущностями, работают с предметами, миром и данными. Каталог разбит на группы по области применения.

PLAYER_MESSAGEСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: PLAYER_COMMUNICATION | targets: any selected entity (players see it)

Sends one chat message to every selected entity. All values of texts are joined into one message.

args:

  • texts (TEXT, up to 27 values): message parts. Numbers, locations, items, lists and game values are turned into text. Default: empty → nothing is sent.

markers:

  • separator: 0 = join values with no separator (default), 1 = join with a space, 2 = join with a new line

notes:

  • The joined message is cut at 1024 characters.
  • Counts toward the plot message limit; if the limit is hit, the program stops.
PLAYER_SEND_TEXT_COMPONENTСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: PLAYER_COMMUNICATION | targets: players

Sends one chat message built from text components (JSON chat text with colors, hover and click events) to every selected player.

args:

  • components (COMPONENT, up to 27 values): message parts. A component value is a JSON chat component ({"comp":{"text":"Hi"}}). Plain text, numbers and variables are added as plain text parts. Default: empty → nothing is sent.

markers:

  • separator: 0 = join parts with no separator (default), 1 = join with a space, 2 = join with a new line

notes:

  • Click action run_command is replaced with suggest_command (the plot cannot run commands as the player).
  • If the component JSON cannot be parsed, it is shown as plain text.

PLAYER_SOUNDСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: PLAYER_COMMUNICATION | targets: players

Plays a sound that only the selected player hears.

args:

  • sound (TEXT): sound id, for example minecraft:entity.experience_orb.pickup or entity.experience_orb.pickup. Required; empty → nothing.
  • volume (NUMBER): volume. Higher volume is heard from farther away. Default: 1. A negative value becomes 1.
  • pitch (NUMBER): pitch, normal range 0.5–2. Default: 1. A negative value becomes 1.
  • location (LOCATION): where the sound comes from. Default: the player's own position.

markers:

  • category: sound category (only changes which volume slider of the player applies): 0 = master (default), 1 = music, 2 = records (jukebox/note blocks), 3 = weather, 4 = blocks, 5 = hostile mobs, 6 = friendly mobs, 7 = players, 8 = ambient, 9 = voice

notes:

  • Color codes are removed from the id and it is lower-cased. Old (pre-1.13) sound names are converted when possible.
  • An id that is not a valid namespaced key is ignored. A valid but unknown id (for example a resource pack sound) is still sent.

PLAYER_SET_ITEMSСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: PLAYER_INVENTORY | targets: players

Puts items into exact inventory slots. The position of a value in the list is the slot.

args:

  • hotbar (ITEM, up to 9 values): hotbar slots 0–8. Value index 0 → slot 0. Use null for an empty slot.
  • main (ITEM, up to 27 values): main inventory slots 9–35. Value index 0 → slot 9. Use null for an empty slot.

markers:

  • state: 0 = empty slots count: every slot without an item is cleared (default), 1 = empty slots are ignored: only slots with an item change

notes:

  • With state 0, every slot you do not fill is cleared, including slots past the end of a short list. Passing only hotbar with state 0 clears the whole main inventory.
  • Armor and off hand are not touched.
