# События

События запускают обработчики кода при наступлении определённых обстоятельств. В этой категории собраны события, связанные с игроками, сущностями и миром.

Подробные статьи по отдельным блокам этой категории ещё готовятся. Здесь будут опубликованы назначение каждого блока, его параметры и настройки, особенности работы и примеры сборки в визуальном редакторе.
:::
