# Основы кодинга Creative+

Creative+ — визуальная система кодинга для создания игровых механик на территории Mineland. Код собирается из блоков в специальной области разработки мира. Блоки не просто выполняются по отдельности: они объединяются в последовательности и обработчики.

## Где находится код

У каждой территории есть собственная область кода — **dev-зона**. В ней размещаются строки кода, каждая из которых начинается с блока-запуска. Дальше к нему добавляются остальные блоки, формирующие логику.

## Три вида обработчиков

| Вид | Для чего нужен |
|---|---|
| **Событие** | Запускает последовательность, когда происходит определённое событие. Например, когда игрок присоединяется к миру. |
| **Функция** | Содержит отдельную последовательность, которая запускается вызовом из другого участка кода. |
| **Цикл** | Повторяет последовательность с заданным интервалом после запуска специальным блоком. |

События, функции и циклы — это не обычные действия внутри последовательности, а разные способы запуска обработчика.

## Порядок выполнения блоков

После стартового блока размещаются действия, условия, блоки выбора целей и управления. Внутри одной последовательности они выполняются **слева направо**, в том порядке, в котором расположены в редакторе.

Условие может содержать вложенные блоки: они выполняются в зависимости от результата проверки. Блоки выбора целей определяют, на каких игроков или сущностей будут воздействовать следующие действия.

## Игровое время

В Creative+ используется игровое время Minecraft: **20 тиков равны одной секунде**. Это важно при настройке ожиданий и интервалов циклов.

## Когда работает код

Код выполняется, когда мир находится в режиме игры. В режиме строительства обработчики не исполняются. При запуске игрового режима код начинает работу, а события запуска мира и присоединения игроков могут инициировать соответствующие последовательности.

## Основные категории блоков

- [События](/guide/events/) запускают обработчики.
- [Действия](/guide/actions/) выполняют игровые операции.
- [Условия](/guide/conditions/) проверяют состояние и управляют ветвлением.
- [Выбор целей](/guide/selection/) задаёт игроков и сущностей, для которых выполняются следующие блоки.
- [Переменные](/guide/variables/) хранят значения между операциями.
- [Коллекции](/guide/collections/) позволяют работать с наборами данных.
- [Управление кодом](/guide/control-flow/) отвечает за ожидания, циклы и вызовы функций.
- [Игровые значения](/guide/game-values/) дают доступ к данным текущей игры.

::: tip Как пользоваться справочником
Открывай статью нужного блока и смотри его назначение, доступные поля редактора, варианты настроек, ограничения и примеры сборки. Технические идентификаторы могут встречаться в скобках как дополнительная справочная информация.
:::

::: warning О точности
Названия элементов интерфейса и доступные настройки должны сверяться с самим редактором Creative+. Если для конкретного блока информация пока не подтверждена, она не должна заменяться предположениями.
:::
