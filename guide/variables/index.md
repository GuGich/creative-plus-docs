# Переменные

Переменные позволяют сохранять значения и использовать их в других блоках. В этом разделе будут описаны операции создания, чтения, изменения и удаления переменных.

::: info Раздел пополняется
Подробные статьи по отдельным блокам этой категории ещё готовятся. Здесь будут опубликованы назначение каждого блока, его параметры и настройки, особенности работы и примеры сборки в визуальном редакторе.
:::

Вернись к [общему каталогу](/guide/), чтобы выбрать другой раздел.
