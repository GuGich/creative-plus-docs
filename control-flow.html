Управление кодом

Блоки управления определяют порядок выполнения: ожидания, циклы, вызовы функций и переходы.

Ниже — справочные записи, извлечённые из технического каталога Creative+. Используй фильтр, чтобы найти нужный идентификатор. Описание передаёт поведение из исходного руководства; названия и расположение блоков в интерфейсе могут отличаться.

5 записей
GAME_WAITСПРАВОЧНАЯ ЗАПИСЬ

kind: control | category: GAME_CODE_UTILITY | targets: none

Pauses the rest of the current node list for some time, then continues.

args:

  • duration (NUMBER, 1 value): how long to wait, in the unit of the state marker. Default: missing or not a number → 1.

markers:

  • state: 0 = ticks, 20 ticks = 1 second (default), 1 = seconds, 2 = minutes

notes:

  • The number is rounded down to a whole number before the unit is applied (1.5 seconds becomes 1 second; use 30 ticks instead).
  • If the current selection is empty, the wait does not happen and the rest of the list never runs.
  • Only the rest of the SAME list waits. A wait inside an if body or a sync function delays only the rest of that body. The nodes after the if, or after the function call, run at once.
  • After the wait the code continues on a new tick with the selection saved at the wait.
  • Max 30 minutes (36000 ticks). A longer wait stops the plot code. The number of waits pending at once is limited per plot.
ELSEСПРАВОЧНАЯ ЗАПИСЬ

kind: control | category: ELSE_IF | targets: none | hidden in menu

The "else" branch of an if chain. Its children run when the IF and all else-if conditions before it are false.

notes:

  • Must have children (an empty list is allowed). Without children the import fails (CHILDREN_REQUIRED).
  • Must come right after the IF node or after an else-if node in the same list. Alone it does nothing.
  • Does not take args, switches, "not" or "elseIf".
ELSE_IFСПРАВОЧНАЯ ЗАПИСЬ

kind: control | category: ELSE_IF | targets: none

An empty else-if block from the editor palette. It does nothing when the code runs.

notes:

  • Do not use it to write an else-if in JSON. Write the condition node with "elseIf": true instead (see the chain above).
  • It must not have children (the import fails with CHILDREN_NOT_ALLOWED). It does not break an if chain.
CALL_FUNCTIONСПРАВОЧНАЯ ЗАПИСЬ

kind: control | category: FUNCTION | targets: none | hidden in menu

Runs the function with the given name.

args:

  • name (TEXT, 1 value): the function name. Required: it must be a plain non-empty text value (not a variable), else the import fails (EMPTY_NAME).

markers:

  • async: 0 = sync, run the function now and wait for it (default), 1 = async, start the function on the next tick and go on at once

notes:

  • These args.name and switches.async are not in the registry dump, but the server reads them (they come from the function sign in the editor).
  • Colors in the name are removed before the lookup. If no function has this name, nothing happens.
  • The function starts with a copy of the current selection. If the current selection is empty, the function is NOT called.
  • A sync call runs inside the caller (depth + 1). Selection changes in the function do not come back to the caller.
  • An async call runs as a new handler on the next tick.
  • Each call counts against the plot action rate limit.
GAME_CALL_FUNCTION_WITH_VARIABLEСПРАВОЧНАЯ ЗАПИСЬ

kind: control | category: GAME_CODE_UTILITY | targets: none (the name is read for every selected target)

Runs a function whose name comes from a text, variable or game value, so the name can change at runtime.

args:

  • name (TEXT, 1 value): the function name. Placeholders are replaced. It may be a variable or a game value.

markers:

  • async: 0 = sync, run now and wait (default), 1 = async, start on the next tick

notes:

  • The name is read for every selected target. Targets that give the same function are grouped, and the function runs once per group with that group as its selection.
  • Targets not in the plot world, and players not playing here, are dropped first. If none are left, nothing is called.
  • Colors in the name are removed. An unknown name is skipped without an error.
  • Each call counts against the plot action rate limit.
