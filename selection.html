Выбор целей

Блоки выбора определяют, к каким игрокам или сущностям применяются следующие действия.

Ниже — справочные записи, извлечённые из технического каталога Creative+. Используй фильтр, чтобы найти нужный идентификатор. Описание передаёт поведение из исходного руководства; названия и расположение блоков в интерфейсе могут отличаться.

The `condition` field (all *_BY_CONDITION selections)СПРАВОЧНАЯ ЗАПИСЬ

SELECT_PLAYERS_BY_CONDITION, SELECT_MOBS_BY_CONDITION, SELECT_ENTITIES_BY_CONDITION, SELECT_ADD_PLAYERS_BY_CONDITION, SELECT_ADD_MOBS_BY_CONDITION, SELECT_ADD_ENTITIES_BY_CONDITION and SELECT_FILTER_SELECTION_BY_CONDITION take a "condition" field instead of args.

  • "condition" is one condition node: {"action":"<CONDITION_ID>","args":{...},"switches":{...},"not":true}. Its args and switches are the args of that condition. It has no children.
  • The condition is tested once for every candidate, with only that candidate as the target. A candidate is kept if the condition is true for it.
  • "not": true inside the condition object keeps the candidates where the condition is false. Do NOT put "not" on the selection node itself: the server rejects it (NOT_CONDITION).
  • "condition" is allowed only on selection nodes. It must name a condition (an IF_* id), else the import fails (NOT_CONDITION).
  • "target" inside the condition is ignored.
  • For players use IF_PLAYER_* or IF_VARIABLE_* conditions. For mobs and entities use IF_ENTITY_* or IF_VARIABLE_*. The filter can use IF_PLAYER_*, IF_ENTITY_*, IF_VARIABLE_* or IF_GAME_*.
  • Game values and placeholders in the condition args are read for the candidate being tested.

Full example: select all sneaking players, then all mobs NOT named "Boss" (ignoring case):

[{"action":"SELECT_PLAYERS_BY_CONDITION","condition":{"action":"IF_PLAYER_SNEAKING"}},{"action":"SELECT_MOBS_BY_CONDITION","condition":{"action":"IF_ENTITY_NAME_EQUALS","args":{"name":"Boss"},"switches":{"case":1},"not":true}}]

SELECT_FROM_ACTIVATORСПРАВОЧНАЯ ЗАПИСЬ

kind: selection | category: CREATE_SELECTION | targets: changes the selection

Selects one participant of the current event, chosen by the marker.

markers:

  • state: 0 = the default target of the event (the player in player events, the entity in entity events) (default), 1 = the event entity (in player events: the other entity of the event, like the clicked or damaged mob; in entity events: the entity itself), 2 = the killer, 3 = the attacker (damager), 4 = the shooter of the projectile, 5 = the projectile, 6 = the victim

notes:

  • If the current selection is empty, the result is empty.
  • If the chosen participant does not exist in this event, the result is empty.

SELECT_DEFAULT_ENTITYСПРАВОЧНАЯ ЗАПИСЬ

kind: selection | category: CREATE_SELECTION | targets: changes the selection

Selects the main entity of the event if it is not a player. Otherwise it selects the last spawned entity.

notes:

  • In player events this gives the last spawned entity, not the event's other entity. Use SELECT_FROM_ACTIVATOR with state 1 for the clicked or damaged mob.
  • The "last spawned entity" is also set to a player when that player joins the plot. Before any spawn or join it is the plot owner.
SELECT_BY_UUIDСПРАВОЧНАЯ ЗАПИСЬ

kind: selection | category: CREATE_SELECTION | targets: changes the selection

Selects players and entities in the plot world by UUID or by exact name.

args:

  • texts (TEXT, up to 27 values): one UUID or name per value. Placeholders are replaced.

notes:

  • If the current selection is empty, the result is empty (the texts are read for the first selected target).
  • A text that is a valid UUID is looked up only as a UUID. Other texts are compared with entity names, case-sensitive. A player's name is the nickname, a mob's name is its custom name or its type name.
  • Each value adds at most one target. Not found values are skipped. No duplicates.

Keeps a given number of random targets from the current selection.

args:

SELECT_FILTER_INVERT_SELECTIONСПРАВОЧНАЯ ЗАПИСЬ

kind: selection | category: FILTER_SELECTION | targets: changes the selection

Replaces the selection with all targets of one kind that are NOT in the current selection.

markers:

  • state: 0 = all players in the plot world that are not selected (default), 1 = all mobs that are not selected, 2 = all non-player entities that are not selected

notes:

  • Targets of the other kinds are dropped. For example with state 0 every mob leaves the selection.
  • If the current selection is empty, the result is empty (it cannot invert an empty selection).
SELECT_FILTER_BY_DISTANCEСПРАВОЧНАЯ ЗАПИСЬ

kind: selection | category: FILTER_SELECTION | targets: changes the selection

Keeps the targets that are within a radius of a location, sorted by distance, up to a limit.

args:

  • center (LOCATION, 1 value): the center point. Default: missing → the selection does not change.
  • radius (NUMBER, 1 value): the radius in blocks. Default: missing → 10. Below 0 → 1.
  • limit (NUMBER, 1 value): the maximum number of targets to keep. Default: missing → 999. Below 0 → 1.

markers:

  • ignoreY: 0 = use the full 3D distance (default), 1 = ignore the Y coordinate (flat distance)
  • selectNearest: 0 = sort nearest first, keep the nearest (default), 1 = sort farthest first, keep the farthest

notes:

  • In both modes only targets inside the radius stay. Targets farther than the radius are removed.
  • The args are read for the first selected target (game values like CURRENT_LOCATION refer to it).
  • The center is moved inside the plot if it is outside. Empty selection stays empty.
SELECT_FILTER_BY_RAY_TRACEСПРАВОЧНАЯ ЗАПИСЬ

kind: selection | category: FILTER_SELECTION | targets: changes the selection

Casts a ray and keeps only the selected targets that the ray hits, nearest first.

args:

  • end (VARIABLE, 1 value): optional variable that receives the end point of the ray (a location).
  • start (LOCATION, 1 value): start of the ray. Its yaw and pitch give the ray direction. Default: missing → empty selection.
  • length (NUMBER, 1 value): ray length in blocks. Default: missing → 10. Max 256. 0 or less → empty selection.
  • width (NUMBER, 1 value): how many blocks to grow every target's hitbox for the hit test. Default: missing → 0.
  • limit (NUMBER, 1 value): the maximum number of targets to keep. Default: missing → 20.

markers:

  • considerBlocks: 0 = the ray stops at the first block it hits (default), 1 = the ray goes through blocks
  • ignorePassable: 0 = passable blocks (grass, flowers) stop the ray (default), 1 = the ray goes through passable blocks
  • ignoreFluids: 0 = water and lava stop the ray (default), 1 = the ray goes through fluids

notes:

  • The args are read for the FIRST target of the selection, and that is a candidate (a mob), not the shooter. So never write {"val":"CURRENT_EYE_LOCATION"} without sel here: save the eye location into a variable BEFORE the SELECT_* and give the variable, or write {"val":"CURRENT_EYE_LOCATION","sel":"DEFAULT"}.
  • After the filter the selection is only the hit targets, so the next node (for example PLAYER_DAMAGE) works only on them.
  • If a block stops the ray, the ray (and end) is cut at the hit point.
  • A target whose hitbox contains the start point is skipped. So a player shooting from his own eyes does not hit himself.
  • Only targets that are already in the selection can be hit. First select candidates (for example SELECT_ALL_ENTITIES), then filter.
  • Empty selection stays empty.
