С чего начать

Базовая модель выполнения кода Creative+ и первые понятия, которые нужно знать перед сборкой механик.

Из чего состоит программа

В Creative+ логика собирается из последовательностей блоков. Каждая последовательность начинается с блока-запускателя, после которого располагаются блоки, выполняемые по порядку.

  • Событие запускает последовательность, когда происходит определённое действие в мире.
  • Функция выполняется, когда её вызывают из другого участка кода.
  • Цикл повторяет последовательность с заданным интервалом после запуска.

Порядок выполнения

Блоки внутри одной последовательности выполняются слева направо. Код работает только в режиме игры. Внутренний игровой такт длится 1/20 секунды: 20 тиков равны одной секунде.

С чего начать

  1. Выбери событие, которое должно запускать механику.
  2. Определи, к кому или чему должны применяться действия.
  3. Добавь проверки, если поведение зависит от условий.
  4. Добавь действия и проверь механику в игровом режиме.
Важно: исходный технический файл также описывает формат импорта и внутренние идентификаторы. Этот сайт постепенно переводит сведения в объяснения для работы с визуальным редактором. Не все параметры JSON являются отдельными видимыми блоками.
