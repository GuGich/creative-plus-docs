Переменные

Переменные сохраняют данные, которые можно читать и менять во время игры.

Ниже — справочные записи, извлечённые из технического каталога Creative+. Используй фильтр, чтобы найти нужный идентификатор. Описание передаёт поведение из исходного руководства; названия и расположение блоков в интерфейсе могут отличаться.

VARIABLE_SETСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: VARIABLE_GENERAL | targets: none

Sets a variable. With one value, the variable gets that value with its own type (number, text, location, item, list and so on). With several values, they are joined into one text.

args:

  • values (ANY, up to 27 values): the new value. Placeholders in texts are replaced. Values that resolve to nothing (for example a missing variable) are skipped. Default: empty → the variable becomes an empty text.
  • variable (VARIABLE): output variable. Required.

markers:

  • separator: used only with several values: 0 = join with no separator (default), 1 = join with a space, 2 = join with a new line

notes:

  • The argument keys are exactly values and variable.
  • With several values, numbers are written in raw form: 5 becomes 5.0. Locations and items become long technical text. To build a text from parts, use VARIABLE_COMBINE_TEXTS instead (it writes 5 as 5).
  • With several values the separator is also added after the last value (separator 1 leaves a space at the end).
  • The joined text is cut at about 1024 characters.
  • Setting a variable to a list or dictionary does not copy it: both variables then point to the same collection.

VARIABLE_GET_RESULT_OF_RAY_TRACEСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: VARIABLE_GENERAL | targets: none

Casts a ray from a location in the direction of its yaw/pitch and writes what it hit into variables.

args:

  • start (LOCATION): start point; its yaw and pitch give the direction. Required.
  • width (NUMBER): thickness of the ray for hitting entities, in blocks. Default: 0. Clamped to 0–8.
  • length (NUMBER): ray length in blocks. Default: 10. Maximum 256. 0 or less → nothing happens.
  • entities (LIST): only entities whose name or UUID is in this list can be hit. Default: not given → any entity.
  • block (VARIABLE): output: location of the hit block (its corner).
  • face (VARIABLE): output: hit side of the block as a text: UP, DOWN, NORTH, SOUTH, EAST or WEST.
  • uuid (VARIABLE): output: UUID of the hit entity, as a text.
  • hit (VARIABLE): output: exact location of the hit point.
  • blocks (BLOCK, up to 18 values): only these block types can be hit; other blocks are passed through. Use item values. Default: empty → every block.

markers:

  • collision: 0 = blocks and entities (default), 1 = only blocks, 2 = only entities
  • ignorePassable: 0 = passable blocks (grass, flowers) stop the ray (default), 1 = the ray goes through passable blocks
  • ignoreFluids: 0 = water and lava stop the ray (default), 1 = the ray goes through fluids

notes:

  • All outputs are optional. An output that has nothing (no hit, or no block / no entity hit) gets an empty value.
  • Entities whose hitbox contains the start point (for example the player at their own eye location) are not hit.
  • Only entities inside the plot can be hit.
  • If entities is a variable that does not exist, the list is empty and no entity can be hit.

  • start (NUMBER): start position, counted from 0, included. Default: 0.

VARIABLE_REPLACE_TEXT_BY_REGEXСПРАВОЧНАЯ ЗАПИСЬ

kind: action | category: VARIABLE_TEXT | targets: none

Replaces matches of a regular expression and writes the result into a variable.

args:

  • variable (VARIABLE): output variable. Required.
  • text (TEXT): the text to change. Required.
  • regex (TEXT): regular expression, Java syntax. Required.
  • replace (TEXT): replacement. $1 inserts group 1, $0 the whole match; write \$ for a real dollar sign and \\ for a backslash. Required (use an empty text to delete matches).

markers:

  • replaces: 0 = replace all matches (default), 1 = replace only the first match
  • ignore: ignore case: 0 = off (default), 1 = on
  • multiline: ^ and $ match at every line: 0 = off (default), 1 = on
  • literal: the regex is plain text (special characters have no meaning): 0 = off (default), 1 = on
  • unix: only \n ends a line: 0 = off (default), 1 = on
  • comments: spaces and # comments are allowed in the regex: 0 = off (default), 1 = on
  • dotall: . also matches a new line: 0 = off (default), 1 = on
  • canon_eq: characters that look the same in Unicode count as equal: 0 = off (default), 1 = on

notes:

  • An invalid regex → nothing happens.
  • The work stops after 100 ms; then the result can be cut.
